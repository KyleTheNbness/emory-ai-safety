01 · Security

Downloading a model can hack you.

Many AI models are shared as Python pickle files, and loading one can run any code its author hid inside. In 2024, researchers at JFrog found about 100 malicious models on Hugging Face. One opened a backdoor on the machine that loaded it.

# a model from a stranger model = torch.load("sentiment-tiny.bin")

Source: The Hacker News, Mar 2024

02 · Speed

AI is starting to help build AI.

Labs already use their models to write code and run experiments. If each generation can make the next one better, progress could speed up faster than our ability to check it. Researchers call this recursive self-improvement.

AI v1→builds→AI v2→builds→AI v3

An illustration, not a forecast.

p(doom) is shorthand for the chance that AI leads to human extinction or something as bad. Guess first, then see what AI researchers said.
